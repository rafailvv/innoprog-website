# Детский раздел ИННОПРОГ

Самописные страницы Next.js / React, без iframe и выполнения Tilda-скриптов.

## Страницы

- `/children` — общий лендинг на основе https://pages.innoprog.ru/children/school.
- `/children/school` — постоянный редирект HTTP 308 на `/children` для старых ссылок.
- `/children/courses/python`
- `/children/courses/web-development`
- `/children/courses/informatics-exams`
- `/children/courses/olympiad-programming`
- `/children/courses/neural-networks`
- `/children/courses/game-development`
- `/children/stories/amir`, `/children/stories/eldar`, `/children/stories/almaz` — полные истории и все 15 фотографий исходных галерей.

Изображения находятся в `public/children/school`. Общий header/footer переиспользуются из основного сайта; параметры детских ссылок не меняют взрослые страницы. Волнистые фоновые полосы исходника визуально убраны по запросу.

## Содержимое

`school/source-data.json` содержит изображения, исходные отзывы и FAQ. В исходнике возраст Алмаза различался между карточкой и полным отзывом; используется возраст 12 лет из полного отзыва. Исправлена двойная запятая в отзыве Эльдара.

`courses/course-data.ts` — редактируемые описания шести направлений. Основные возрастные границы, цена, формат и направления взяты из исходного сайта. Разделы программы и примеры практики написаны для детальных страниц; это ориентировочные маршруты, адаптируемые преподавателем, а не утверждённые учебные планы или гарантии конкретного количества занятий. Перед публикацией можно уточнить содержание этого файла.

## Заявки

`school/LeadForm.tsx` используется для общей страницы, модальных окон и отдельной формы каждого курса. Форма требует согласие на обработку данных, получает Yandex SmartCaptcha token и отправляет JSON на существующий `/application/request`. В `question` передаётся выбранный курс; `form_id` у детальных курсов уникальный (`children-<slug>`). Успех отображается только после успешного ответа сервера, повторная отправка блокируется во время запроса.

Прокси `src/app/api/application/request/route.ts` определяет `site_audience` по нормализованному адресу страницы: `/children` и `/children/*` — `children`, остальные — `adults`. Клиентская метка не используется. Обработчик в отдельном репозитории `innoprog_bot/bot_api/bot_interaction.py` включает в сообщение Telegram «С сайта для детей» или «С сайта для взрослых». Для появления меток в production нужны изменения обоих репозиториев.

Форма запрашивает имя родителя, имя и возраст ребёнка, телефон, направление, необязательные email и пожелания. Согласие на обработку данных обязательно; рекламное согласие отдельно и по умолчанию выключено. Кнопка «Отправить» доступна во всех формах, включая модальные окна. Капча обязательна; на локальном домене её работа зависит от разрешённых доменов ключа. Тесты подменяют капчу, HTTP и Telegram, не отправляя настоящие заявки.

## SEO

Все 10 страниц имеют серверный HTML, уникальные title/description, canonical, собственные Open Graph изображения 1200×630, разрешённую индексацию и включены в sitemap. Курсы содержат Course, CourseInstance, BreadcrumbList, FAQPage и WebPage JSON-LD. Истории размечены как Article без выдуманных рейтингов. Это готовность к индексации после публикации; локальные страницы не появляются в поиске.
