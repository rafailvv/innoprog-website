# Публичные документы раздела `/sveden`

Исходным комплектом служит ZIP, переданный образовательной организацией на дату 01.08.2026. Скрипт принимает архив явно, извлекает только разрешённые PDF из папок `01`–`14` и `98`, заменяет устаревшие сведения о вакантных местах приказом № ОБР-10, добавляет два опубликованных технических PDF, утверждённые положения, приказы № ОБР-7, № ОБР-9, № ОБР-10, № ОБР-11 и № ОБР-12, утверждённые редакции от 02.08.2026, шесть детских программ и приказы № ОБР-13 и № ОБР-14 от 05.08.2026, затем формирует ровно 110 файлов вместе с manifest. Отменённые редакции хранятся только во внутреннем архиве.

```bash
python3 -m venv .venv-sveden
.venv-sveden/bin/pip install -r scripts/requirements-sveden.txt
.venv-sveden/bin/python scripts/prepare-sveden-documents.py /path/to/source.zip \
  --supplemental-dir /path/to/approved-credit-policy-files \
  --updates-dir /path/to/approved-2026-08-02-pdf-files \
  --program-updates-dir /path/to/signed-professional-programs \
  --child-programs-dir /path/to/child-programs-and-order-obr-13 \
  --offer-file /path/to/ПУБЛИЧНАЯ_ОФЕРТА_INNOPROG_ОТ_02.08.2026.pdf
.venv-sveden/bin/python scripts/verify-sveden-documents.py
```

В `--supplemental-dir` должны находиться исходные подписанные PDF с названиями, указанными в `SUPPLEMENTAL_DOCUMENT_FILES`. В `--updates-dir` должны находиться утверждённые PDF с именами из `UPDATE_FILES`; действующие документы заменяют прежние редакции по стабильным URL. В `--program-updates-dir` передаются девять подписанных редакций дополнительных профессиональных программ, утверждённых приказом № ОБР-11 от 02.08.2026; скрипт публикует их под существующими русскими именами и стабильными URL. В `--child-programs-dir` передаются шесть утверждённых программ для детей и приказы № ОБР-13 и № ОБР-14. Параметр `--offer-file` принимает действующую редакцию публичной оферты и заменяет предыдущую редакцию в разделе платных услуг и по адресу `/oferta`. При необходимости два технических оригинала можно передать локально через `--technical-dir`. Без этого параметра они загружаются из публичного S3-префикса до применения обновления инструкции. Для проверки только локального комплекта используется `--skip-remote`; по умолчанию дополнительно проверяются все 110 URL на `innoprog.ru`, размер, PDF Content-Type, `X-Robots-Tag: noindex` и Range-ответ `206`.

ZIP, DOCX, RTF, матрица, техническое задание, подписи и иные служебные файлы в staging и S3 не попадают. Папки `00` и `99` не обрабатываются.
