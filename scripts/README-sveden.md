# Публичные документы раздела `/sveden`

Исходным комплектом служит ZIP, переданный образовательной организацией на дату 01.08.2026. Скрипт принимает архив явно, извлекает только разрешённые PDF из папок `01`–`14` и `98`, заменяет устаревшие сведения о вакантных местах приказом № ОБР-10, добавляет два опубликованных технических PDF, утверждённые положения, приказы № ОБР-7, № ОБР-9, № ОБР-10, № ОБР-11 и № ОБР-12 и утверждённые редакции от 02.08.2026, затем формирует ровно 101 файл вместе с manifest.

```bash
python3 -m venv .venv-sveden
.venv-sveden/bin/pip install -r scripts/requirements-sveden.txt
.venv-sveden/bin/python scripts/prepare-sveden-documents.py /path/to/source.zip \
  --supplemental-dir /path/to/approved-credit-policy-files \
  --updates-dir /path/to/approved-2026-08-02-pdf-files \
  --offer-file /path/to/ПУБЛИЧНАЯ_ОФЕРТА_INNOPROG_ОТ_02.08.2026.pdf
.venv-sveden/bin/python scripts/verify-sveden-documents.py
```

В `--supplemental-dir` должны находиться исходные подписанные PDF с названиями, указанными в `SUPPLEMENTAL_DOCUMENT_FILES`. В `--updates-dir` должны находиться утверждённые PDF с именами из `UPDATE_FILES`; они заменяют прежние редакции по стабильным URL, а приказ № ОБР-12 заменяет старый безномерный приказ по новому каноническому URL. Параметр `--offer-file` принимает действующую редакцию публичной оферты и заменяет предыдущую редакцию в разделе платных услуг и по адресу `/oferta`. При необходимости два технических оригинала можно передать локально через `--technical-dir`. Без этого параметра они загружаются из публичного S3-префикса до применения обновления инструкции. Для проверки только локального комплекта используется `--skip-remote`; по умолчанию дополнительно проверяются все 101 URL на `innoprog.ru`, размер, PDF Content-Type, `X-Robots-Tag: noindex` и Range-ответ `206`.

ZIP, DOCX, RTF, матрица, техническое задание, подписи и иные служебные файлы в staging и S3 не попадают. Папки `00` и `99` не обрабатываются.
