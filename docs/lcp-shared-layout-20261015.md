# Изоляция общей разметки от главной страницы — 15 октября 2026

## Подтверждённая причина

`ResponsiveSiteHeader` и `ResponsiveSiteFooter` импортировали именованные компоненты из больших модулей `MainScreenDesktop` и `MainScreenMobile`. Девять мобильных страниц взрослых курсов также получали блок преподавателей из `MainScreenMobile`. Поэтому простой `next/dynamic` для главной не создавал отдельные загружаемые файлы: оставались статические входы в те же модули.

## Изменение

- Вынесены неизменённые desktop/mobile header и footer в отдельные файлы `src/imports/shared/`.
- Вынесен мобильный блок преподавателей; сохранены `preferredRole`, порядок карточек, классы, размеры и атрибуты карусели.
- Общие обёртки и мобильные курсы импортируют эти компоненты напрямую.
- Главная использует те же общие компоненты. Прежние именованные экспорты сохранены для совместимости.
- SVG-пути перенесены без изменения координат; в каждом компоненте оставлены только используемые пути. Из home-объектов убраны перенесённые и неиспользуемые пути, чтобы не дублировать их в отдельном home chunk.
- Только два компонента главной в `App.tsx` переведены на `next/dynamic` с включённым SSR по умолчанию. Тексты и ссылки не заменены клиентскими заглушками.

Разметка и функции обработчиков не переписаны; обработчики остаются в существующем `App.tsx`. Маршруты, программы, формы, цены, доступность навигации и поведение закрытого мобильного меню не изменены.

Исходные копии используются только во временной проверке и не входят в выпуск.

Production build и проверка фактического `react-loadable-manifest` и начального JavaScript у главной, взрослого курса и детских страниц выполняются после общей интеграции.
