## Реализовано

1. Title каталога уточняет «курсы» и онлайн-формат. Метаданные веба называют HTML/CSS/JavaScript; игр — Unreal Engine; нейросетей — разработку; олимпиад — онлайн-формат.
2. Четыре существующих вопроса FAQ и их закрытое состояние сохранены. Для каждого курса уникализированы подготовка, формат практики и инструменты по опубликованным программам. Новых блоков нет.
3. В ответе о подготовке — осмысленная ссылка на смежный маршрут: Python↔нейросети, экзамены↔олимпиады, веб→Python, игры→веб. Это обычные серверные ссылки, доступные в HTML без JavaScript. Дополнительные пояснения видны после раскрытия FAQ.
4. Один источник FAQ формирует видимый текст и JSON-LD; тест проверяет их буквальное соответствие для шести страниц.
5. Сроки, цены, возраст, гарантии, преподаватели, CTA и формы не изменены. Фиксированные технические требования компьютера не придуманы.

## Следующий этап при появлении данных

- Выгрузки Вебмастера/Search Console: реальные показы, запросы, конкурирующие URL и индексирование.
- Wordstat/другой инструмент частотности: проверка формулировок, географии и сезонности экзаменов.
- Отдельные ОГЭ/ЕГЭ URL — только при подтверждённом спросе и самостоятельных программах, а не автоматическое дробление.
- Roblox, Unity, Scratch, возрастные и городские страницы не создавать по догадке.
