## Требуется внешний доступ или подтверждение

1. В Метрике создать/проверить цели типа «Целевое событие» с идентификаторами `application_success`, `contact_telegram`, `contact_whatsapp`, `contact_phone`. Проверить их приём в кабинете и затем сравнивать реальные заявки по источникам. API: https://yandex.ru/support/metrica/ru/objects/reachgoal.
2. В Яндекс Вебмастере и Google Search Console проверить индексирование, исключённые URL, sitemap, фактические запросы/позиции и CWV. Публичный обход не может заменить эти данные.
3. Для рейтинга 4,9, статистики трудоустройства и гарантий/возвратов нужны источник оценок, методика и действующие условия договора. Дополнительные обещания и aggregateRating не добавлены.
4. Фиксированный ТОП-10, расширенный сниппет или сроки роста не гарантируются. Schema.org/FAQ не дают автоматического права на расширенный результат.
5. Google PageSpeed API при этой проверке вернул превышение суточной квоты. Новые LCP/INP/CLS не измерены. Снижение объёма файлов подтверждено; процент ускорения страницы не заявляется.
